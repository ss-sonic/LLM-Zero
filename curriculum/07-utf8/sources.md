# Lesson 07 sources

Primary references used to verify the UTF-8 mechanics taught in this lesson:

- The Unicode Standard, Version 17.0, especially the encoding-form discussion and UTF-8 bit distribution: https://www.unicode.org/versions/Unicode17.0.0/UnicodeStandard-17.0.pdf
- RFC 3629, UTF-8, a transformation format of ISO 10646: https://www.rfc-editor.org/rfc/rfc3629.html

Lesson scope intentionally stops before a detailed treatment of ill-formed sequences, overlong encodings, surrogate exclusions, BOM behavior, or UTF-16/UTF-32 tradeoffs.
